md_center · Design System · Final · 2026.05

Mobile App · Final Designs

私有影视媒体库的 iOS / Android 客户端,服务于自建片源 + 重元数据的影迷收藏者。 多彩集合方向 · 亮暗双版本 · 系统跟随。

11 屏 · 4 模块 Light + Dark R18 隐私层 Inter / SF Mono
I

核心模块

01 · CORE

Library + Favorites

影片库全量浏览 + 强筛选 + 多视图 · 收藏夹列表管理 + Watchlist + AI 提醒。R18 遮罩 / PIN 私密列表已加入。
LIGHT DARK 4 屏
02 · DETAIL

Movie Detail + Person Detail

影片详情页 (Hero / 演员阵容 / 元数据 / 同导演作品) · 演员/导演个人页 (作品集 retrospective)。
LIGHT DARK 2 屏
03 · NAV

Browse · Search · Settings · Player

Browse 维度浏览中枢 (Directors / Genres / Tags / Years) · 搜索页 · 设置页 · 播放器 UI。
LIGHT DARK 4 屏
04 · ONBOARD

First Launch · Server Setup

首次启动引导 · 服务器配置流程 · 连接测试 · 库扫描进度。冷启动到「能用」的全链路。
LIGHT DARK 3 屏

III

目标群体

PRIMARY

自建媒体库收藏者

Plex / Jellyfin / Emby 用户的进阶人群,嫌默认 UI 不够好看,要客厅大屏感 + 元数据深度。重视演员、导演、年代、标签等浏览维度。
SECONDARY

Letterboxd 重度影迷

习惯按导演/系列/类型追溯,在意评分 + 注解 + 收藏列表。R18 遮罩与隐私模式确保混合内容场景下的体面。
CONTEXT

移动 + 客厅协同

移动端是「选片 · 浏览 · 管理」入口,投屏到电视播放。所以 Library 网格密度可以高,但 Movie Detail 必须做到 hero 级。
IV

无
